# Cloudflare Pages Deployment

## Files to Deploy
All HTML files in this directory will be deployed to Cloudflare Pages.

## Deployment Steps
1. Go to Cloudflare Dashboard
2. Navigate to Pages
3. Create a new project
4. Upload files or connect to Git repository
5. Configure custom domain

## Custom Domain
Target: shop.keleshteri.eu.org

- product.html
